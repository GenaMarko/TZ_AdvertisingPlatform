-----------------[Требования]---------------------------------
Установленный ".NET 8.0 SDK".
Ссылка для скачивания: 
https://dotnet.microsoft.com/en-us/download
--------------------------------------------------------------

-----------------[Как запустить]------------------------------
Открыть консоль с директорией проекта (TZ_AdvertisingPlatform)
и ввести команду "dotnet run", после чего по адресу 
"http://localhost:ВашПорт/swagger" будет доступен веб-сервис
--------------------------------------------------------------

-----------------[Как использовать]---------------------------
В директории проекта есть файл "data.txt", который содержит в 
себе данные о рекламных площадках и их регионах. 

Метод POST "/AdvertisingPlatform/Load" загружает данные из 
файла "data.txt" в коллекцию. При повторном вызове он 
перезапишет коллекцию заново.

Метод GET "/AdvertisingPlatform/GetByLocation"  
возвращает список рекламных площадок, действующих 
в заданной локации.
